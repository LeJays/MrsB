🔑 Autorisation Firestore (Règles Firebase)

Votre projet Firebase mrsb-15e64 bloque l'enregistrement cloud car la collection clients n'est pas encore déclarée dans les règles de sécurité Firestore.

1. Règle à ajouter dans Firebase Console
match /clients/{document=**} { allow read, write: if request.auth != null; }
Procédure rapide (1 minute) :
1. Ouvrez votre Console Firebase → Onglet Règles (Rules).
2. Collez la règle ci-dessus à l'intérieur du bloc match /databases/{database}/documents { ... }.
3. Cliquez sur Publier (Publish).
4. Revenez ici et cliquez sur Tester la synchronisation !
